# SMALL CIRCLE

Vercel-ready static site with serverless passkey authentication.

## Vercel environment variables

- `PASSKEY` = `CIRCLE`
- `AUTH_SECRET` = a unique random string of at least 16 characters

## Deploy

Upload the **contents of this folder** to the root of the GitHub repository. In Vercel, leave **Root Directory** blank and redeploy.

## Test

```bash
npm test
```
